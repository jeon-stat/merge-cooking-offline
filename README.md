# Merge Cooking Offline — 개인 작업본 (iPad PWA)

권리자가 허용한 개인용·오프라인·비상업적 범위 안에서 진행하는 iPad용 구현 작업본입니다. 저장은 iPad/Safari의 `localStorage`에만 남으며, 서버·광고·결제·계정 기능은 없습니다.

> 공개 자료로 확인 가능한 진행 구조를 우선 구현한 개인용 작업본입니다. 원본의 서버·라이브 이벤트·광고·결제는 의도적으로 제외하고, 로컬 플레이는 무제한으로 동작합니다.

## iPad에서 실행하기

PWA는 `https://` 또는 같은 Wi-Fi의 로컬 웹 서버에서 열어야 서비스 워커(완전 오프라인 캐시)가 활성화됩니다.

1. 이 폴더의 `dist` 안의 파일을 개인 GitHub 저장소의 루트에 올립니다.
2. GitHub Pages를 켜거나, 같은 Wi-Fi에서 정적 웹 서버로 `dist`를 제공합니다.
3. iPad Safari에서 주소를 열고 **공유 → 홈 화면에 추가**를 선택합니다.
4. 처음 한 번 정상적으로 열어 둔 뒤에는 인터넷이 없어도 홈 화면 아이콘에서 실행됩니다.

## 현재 구현·연구 범위

- 로컬에서 동작하는 7 × 9 병합 보드
- 같은 아이템 두 번 탭 병합과 포인터 드래그 이동·병합
- 생성기 레벨 표시, 같은 생성기 드래그 병합, 레벨별 공개 출력
- 과일·음료·프로틴·채소·곡물·알코올·배 생성기 데이터와 과일·견과·음료·커피·어류·패류 공개 체인
- 주문 납품, 코인, 식당 개조 포인트 기반 스테이지 해금, 미국·프랑스·일본 공개 스테이지 목록
- 주문 카드의 준비 상태 표시와 미준비 주문 조합 힌트
- 스테이지별 생성기·조리기구 배치와 주서기·셰프 카운터·팬·그릴·오븐·조리 냄비 레시피
- 공개 국가별 표에서 기본 재료만으로 재현 가능한 프랑스·일본 요리(바게트·훈제 연어·오리 콩피·낫토·야키토리·사시미 등)
- 일본의 매력 생성기와 대나무·여우 기념품, 홍합 파생품, 밥공기·초밥용 발 하위 생성 흐름
- 재료 체인·조리기구 레시피 도감
- 냉장 보관함 8칸
- 브라우저 내 자동 저장과 진행 초기화

공개 레시피 중 별도 레시피 카드·이벤트 재료가 필요한 조합은 카드 시스템을 먼저 구현한 뒤 추가할 수 있도록 데이터 출처만 기록하고, 현재 주문 풀에는 넣지 않았습니다. 따라서 현재 표시되는 주문은 해금된 생성기와 조리기구로 끝까지 만들 수 있습니다.

## iPad 네이티브 앱으로 전환

앱스토어/IPA용 패키지에는 macOS와 Xcode가 필요합니다. 현재 `dist`는 Capacitor 같은 웹뷰 래퍼로 감싸 iPad 앱으로 옮길 수 있는 정적 오프라인 앱입니다.
