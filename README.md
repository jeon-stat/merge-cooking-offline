# Merge Cooking Offline — 개인 작업본 (iPad PWA)

권리자가 허용한 개인용·오프라인·비상업적 범위 안에서 진행하는 iPad용 구현 작업본입니다. 저장은 iPad/Safari의 `localStorage`에만 남으며, 서버·광고·결제·계정 기능은 없습니다.

> 현재 코드는 첫 번째 스테이지의 공개 자료를 바탕으로 게임 시스템을 구성하는 초기 단계입니다. 원본과의 플레이 동등성, 전체 스테이지·스토리·밸런스는 아직 검증 또는 완성되지 않았습니다.

## iPad에서 실행하기

PWA는 `https://` 또는 같은 Wi-Fi의 로컬 웹 서버에서 열어야 서비스 워커(완전 오프라인 캐시)가 활성화됩니다.

1. 이 폴더의 `dist`를 개인 GitHub 저장소에 올립니다.
2. GitHub Pages를 켜거나, 같은 Wi-Fi에서 정적 웹 서버로 `dist`를 제공합니다.
3. iPad Safari에서 주소를 열고 **공유 → 홈 화면에 추가**를 선택합니다.
4. 처음 한 번 정상적으로 열어 둔 뒤에는 인터넷이 없어도 홈 화면 아이콘에서 실행됩니다.

## 현재 구현·연구 범위

- 로컬에서 동작하는 7 × 6 병합 보드 프로토타입
- 과일·식료품·조리대 생성기
- 주문 납품, 코인, 식당 개조의 기반 구조
- 냉장 보관함 8칸
- 브라우저 내 자동 저장과 진행 초기화

## iPad 네이티브 앱으로 전환

앱스토어/IPA용 패키지에는 macOS와 Xcode가 필요합니다. 현재 `dist`는 Capacitor 같은 웹뷰 래퍼로 감싸 iPad 앱으로 옮길 수 있는 정적 오프라인 앱입니다.

## 권리 및 사용 조건

이 프로젝트는 권리자로부터 받은 개인용·오프라인·비상업적 이용 허가 범위에서만 사용합니다. 관련 허가 메일은 이 저장소에 올리지 말고 별도로 보관하세요. 원본 코드의 추출, 결제/보호 우회, 허가 범위를 넘는 배포는 포함하지 않습니다.
